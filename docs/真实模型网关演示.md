# 真实模型网关演示

本文档用于验证 `Planner` 和 `Report` 通过 Model Gateway 调用真实 OpenAI-compatible 模型服务。

## 配置项

核心环境变量：

```powershell
$env:SHOPOPS_MODEL_OPENAI_COMPATIBLE_ENABLED="true"
$env:SHOPOPS_MODEL_OPENAI_COMPATIBLE_BASE_URL="https://api.openai.com/v1"
$env:SHOPOPS_MODEL_OPENAI_COMPATIBLE_API_KEY="你的 API Key"
$env:SHOPOPS_MODEL_OPENAI_COMPATIBLE_DEFAULT_MODEL="gpt-4o-mini"

$env:SHOPOPS_MODEL_GATEWAY_PLANNER_ENABLED="true"
$env:SHOPOPS_MODEL_GATEWAY_REPORT_ENABLED="true"
```

`BASE_URL` 需要是不带 `/chat/completions` 的 OpenAI-compatible 根路径，系统会自动拼接 `/chat/completions`。

## 一键启动

OpenAI-compatible 远程服务：

```powershell
.\scripts\start-model-gateway-demo.ps1 `
  -BaseUrl "https://api.openai.com/v1" `
  -ApiKey "你的 API Key" `
  -Model "gpt-4o-mini" `
  -Port 8080
```

Ollama 本地服务：

```powershell
.\scripts\start-model-gateway-demo.ps1 `
  -BaseUrl "http://localhost:11434/v1" `
  -Model "qwen2.5:7b" `
  -AllowNoApiKey `
  -Port 8080
```

## 验证调用

服务启动后，在另一个 PowerShell 窗口执行：

```powershell
.\scripts\verify-model-gateway-demo.ps1 -Port 8080
```

期望结果：

- `daily_review` 任务创建成功。
- 报告内容来自模型输出。
- `/api/admin/model-gateway/call-logs` 中能看到 `daily_review.plan` 和 `daily_review.report` 两类调用日志。

如果模型规划输出不符合安全 JSON 结构，Planner 会自动回退规则计划；如果报告模型调用失败，Report 会自动回退规则版报告。
