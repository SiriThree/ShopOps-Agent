# ShopOps Agent 本地开发启动指南

## 1. 环境要求

后端工程基于 Spring Boot 3 和 Java 17。

必须安装：

```text
JDK 17+
Maven 3.9+
Docker Desktop
Git
```

检查命令：

```bash
java -version
mvn -version
docker version
docker compose version
```

注意：Java 8 无法运行本项目，因为 Spring Boot 3 要求 Java 17。

## 2. 启动开发基础设施

在项目根目录执行：

```bash
docker compose -f deploy/docker-compose.dev.yml up -d
```

启动服务：

```text
MySQL    localhost:3306 / root:root / shopops_agent
Redis    localhost:6379
RabbitMQ localhost:5672
RabbitMQ UI http://localhost:15672 / shopops:shopops
```

MySQL 首次启动时会自动执行：

```text
sql/shopops_p0_schema.sql
sql/shopops_p0_seed.sql
```

如果需要重新初始化数据库：

```bash
docker compose -f deploy/docker-compose.dev.yml down -v
docker compose -f deploy/docker-compose.dev.yml up -d
```

## 3. memory 模式启动

默认配置：

```yaml
shopops:
  persistence: memory
```

memory 模式使用内存版 Service，不依赖数据库数据，适合快速验证主链路。

启动：

```bash
mvn clean install -DskipTests
mvn -pl shopops-admin spring-boot:run
```

## 4. jdbc 模式启动

jdbc 模式会使用 MyBatis 写入 P0 核心表：

```text
mcp_tool
agent_task
agent_task_step
agent_task_event
tool_call_log
operation_report
trace_span
```

确认 `shopops-admin/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/shopops_agent?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: root

shopops:
  persistence: jdbc
```

也可以不改文件，用命令行参数启动：

```bash
mvn clean install -DskipTests
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.arguments=--shopops.persistence=jdbc"
```

## 5. 验证 P0 每日经营复盘

创建任务：

```bash
curl -X POST http://localhost:8080/api/agent/tasks \
  -H "Content-Type: application/json" \
  -H "X-Tenant-Id: 1" \
  -H "X-Shop-Id: 1" \
  -H "X-User-Id: 1" \
  -d '{
    "taskType": "daily_review",
    "userInput": "帮我生成今天店铺运营复盘",
    "dateRange": {
      "start": "2026-07-18",
      "end": "2026-07-18"
    }
  }'
```

返回示例：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "taskId": 10001,
    "taskNo": "TASK2026071814000010001",
    "status": "SUCCESS",
    "traceId": "tr_xxx"
  }
}
```

查询任务：

```bash
curl http://localhost:8080/api/agent/tasks/10001
```

查询步骤：

```bash
curl http://localhost:8080/api/agent/tasks/10001/steps
```

查询 Trace：

```bash
curl http://localhost:8080/api/tasks/10001/trace
```

查询报告：

```bash
curl http://localhost:8080/api/reports/90001
```

报告 ID 以创建任务返回的 `reportId` 或任务详情中的 `reportId` 为准。

## 7. 常见问题

### 7.1 mvn 命令不存在

安装 Maven，并确认 `mvn -version` 可用。

### 7.2 Java 版本是 1.8

安装 JDK 17，并调整 `JAVA_HOME` 和 `PATH`。

### 7.3 MySQL 初始化 SQL 没有执行

MySQL Docker 镜像只会在数据目录为空时执行 `/docker-entrypoint-initdb.d`。

重新初始化：

```bash
docker compose -f deploy/docker-compose.dev.yml down -v
docker compose -f deploy/docker-compose.dev.yml up -d
```

### 7.4 jdbc 模式启动失败

检查：

- MySQL 容器是否启动。
- 数据库 `shopops_agent` 是否存在。
- `mcp_tool` 是否已有 P0 工具数据。
- `application.yml` 中账号密码是否正确。

### 7.5 GitHub push 失败

如果提示无法连接 `github.com:443`，通常是网络问题。网络恢复后执行：

```bash
git push -u origin main
```
