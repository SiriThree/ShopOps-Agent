# ShopOps Agent 本地开发启动指南

## 1. 环境要求

后端基于 Spring Boot 3 和 Java 17。

```text
JDK 17+
Maven 3.9+
Docker Desktop
Git
```

检查命令：

```powershell
java -version
mvn -version
docker version
docker compose version
```

如果 Maven 找不到 JDK，可以在当前 PowerShell 临时设置：

```powershell
$env:JAVA_HOME='C:\Program Files\Microsoft\jdk-17.0.19.10-hotspot'
$env:Path="$env:JAVA_HOME\bin;C:\Tools\apache-maven-3.9.16\bin;$env:Path"
```

## 2. 启动开发基础设施

在项目根目录执行：

```powershell
docker compose -f deploy/docker-compose.dev.yml up -d
docker compose -f deploy/docker-compose.dev.yml ps
```

本地服务：

```text
MySQL    localhost:3306 / root:root / database: shopops_agent
Redis    localhost:6379
RabbitMQ localhost:5672
RabbitMQ UI http://localhost:15672 / shopops:shopops
```

MySQL 容器只负责创建空数据库。表结构和样例数据由后端启动时的 Flyway 迁移管理，迁移文件位于：

```text
shopops-admin/src/main/resources/db/migration
```

## 3. memory 模式启动

默认模式是 `memory`，不依赖 MySQL 数据，适合快速验证主链路。

```powershell
mvn clean install -DskipTests
mvn -pl shopops-admin spring-boot:run
```

## 4. dev JDBC 模式启动

`dev` profile 会连接 Docker Compose 启动的 MySQL，并启用 Flyway 迁移。

```powershell
mvn clean install -DskipTests
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.profiles=dev"
```

看到下面这些日志含义，就说明数据库迁移链路正常：

```text
Flyway ... Successfully validated
Schema `shopops_agent` is up to date
Tomcat started on port 8080
```

## 5. 创建每日经营复盘任务

PowerShell 推荐使用 `Invoke-RestMethod`，避免 `curl.exe` 的 JSON 转义问题。

```powershell
$body = @{
  taskType = "daily_review"
  userInput = "帮我生成今天店铺运营复盘"
  dateRange = @{
    start = "2026-07-18"
    end = "2026-07-18"
  }
} | ConvertTo-Json -Depth 5

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/agent/tasks" `
  -Headers @{
    "X-Tenant-Id" = "1"
    "X-Shop-Id" = "1"
    "X-User-Id" = "1"
  } `
  -ContentType "application/json; charset=utf-8" `
  -Body $body
```

## 6. 常用验证 API

把 `{taskId}` 和 `{reportId}` 替换为创建任务返回的数据。

```powershell
Invoke-RestMethod -Method Get -Uri "http://localhost:8080/api/agent/tasks/{taskId}"
Invoke-RestMethod -Method Get -Uri "http://localhost:8080/api/agent/tasks/{taskId}/steps"
Invoke-RestMethod -Method Get -Uri "http://localhost:8080/api/tasks/{taskId}/trace"
Invoke-RestMethod -Method Get -Uri "http://localhost:8080/api/reports/{reportId}"
Invoke-RestMethod -Method Get -Uri "http://localhost:8080/api/system/health"
```

Swagger 地址：

```text
http://localhost:8080/swagger-ui.html
```

## 7. 常见问题

### docker compose ps 提示找不到配置

需要带上 compose 文件：

```powershell
docker compose -f deploy/docker-compose.dev.yml ps
```

### JDBC 模式连接 MySQL 失败

检查容器是否运行：

```powershell
docker compose -f deploy/docker-compose.dev.yml ps
```

再确认启动命令使用了 `dev` profile：

```powershell
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.profiles=dev"
```

### 想重建本地数据库

这会删除 Docker volume 中的本地数据：

```powershell
docker compose -f deploy/docker-compose.dev.yml down -v
docker compose -f deploy/docker-compose.dev.yml up -d
```

随后重新启动后端，Flyway 会从空库执行迁移。

## 8. 当前数据链路

JDBC 模式下，Agent 编排链路保持不变，工具底层数据来自 MySQL：

```text
order.query_summary      -> shop_order / shop_order_item
comment.query_negative   -> product_comment
product.query_candidates -> product / order / comment 聚合
report.generate_daily_review -> operation_report
```
