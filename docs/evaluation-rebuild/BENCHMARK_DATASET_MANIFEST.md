# ShopOpsBench v1 — Dataset Manifest

The machine-readable frozen manifest is:

```text
shopops-admin/src/test/resources/benchmark/v1/benchmark-manifest-v1.json
```

It is generated by:

```bash
python3 scripts/generate-benchmark-manifest.py
```

and verified by:

```bash
python3 scripts/verify-benchmark-manifest.py
```

## Freeze semantics

The manifest records:

- benchmark and per-benchmark dataset version;
- Gold version;
- schema SHA-256;
- per-split selected case IDs;
- canonical SHA-256 for the selected cases;
- held-out case IDs and counts.

A held-out run must verify the frozen manifest first. A Gold correction requires a dataset version increment and a regenerated manifest. A failed held-out case must not simply be deleted while retaining the same version.
