# 外部业务数据源演示

当前版本先完成经营复盘核心业务输入的最小连接器闭环：`order.query_summary`、`comment.query_negative`、`product.query_candidates` 在 memory 模式下可以从 JSON 文件读取数据；未配置文件或未命中日期时，仍回退到内置演示数据。连接器状态、凭证掩码、轮换提醒、同步任务和外部调用日志可以在 `/admin/connectors.html` 查看，也可以通过 `GET /api/admin/connectors/status` 做接口验收。

docs/demo-data/negative-comments-demo.json
docs/demo-data/product-candidates-demo.json

## 2. 启动方式

使用示例文件启动：

```powershell
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.arguments=--shopops.connector.order-summary.file=docs/demo-data/order-summary-demo.json --shopops.connector.negative-comments.file=docs/demo-data/negative-comments-demo.json --shopops.connector.product-candidates.file=docs/demo-data/product-candidates-demo.json"
```

如果端口被占用，可以同时指定端口：

```powershell
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.arguments=--server.port=8081 --shopops.connector.order-summary.file=docs/demo-data/order-summary-demo.json --shopops.connector.negative-comments.file=docs/demo-data/negative-comments-demo.json --shopops.connector.product-candidates.file=docs/demo-data/product-candidates-demo.json"
```

## 3. 验证订单接口

```powershell
$headers = @{
  "Content-Type" = "application/json"
  "X-Tenant-Id" = "1"
  "X-Shop-Id" = "1"
  "X-User-Id" = "1"
  "X-User-Roles" = "ADMIN"
}

$body = @{
  shopId = 1
  startDate = "2026-07-18"
  endDate = "2026-07-18"
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/tools/order.query_summary/invoke" `
  -Headers $headers `
  -Body $body
```

期望结果：

- `data.gmv` 为 `156780.25`。
- `data.orderCount` 为 `963`。
- `data.connectorCode` 为 `file.order-summary`。

## 4. 验证连接器状态

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "http://localhost:8080/api/admin/connectors/status" `
  -Headers $headers
```

期望结果：

- `file.order-summary` 状态为 `UP`。
- `file.negative-comments` 状态为 `UP`。
- `file.product-candidates` 状态为 `UP`。
- 如果某个文件配置项为空，状态会显示为 `NOT_CONFIGURED`，对应工具仍会回退到内存默认数据。

前端页面：

```text
http://localhost:8080/admin/connectors.html
```

凭证管理接口：

```powershell
$credentialBody = @{
  connectorCode = "file.order-summary"
  credentialType = "API_KEY"
  secretValue = "sk-demo-secret"
  expiresAt = "2026-12-31"
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/admin/connectors/credentials" `
  -Headers $headers `
  -Body $credentialBody

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/admin/connectors/credentials/file.order-summary/test" `
  -Headers $headers

Invoke-RestMethod `
  -Method Get `
  -Uri "http://localhost:8080/api/admin/audit/timeline?source=CONNECTOR&pageNum=1&pageSize=10" `
  -Headers $headers
```

期望结果：

- 保存凭证只返回 `maskedSecret`，不会返回 `secretValue` 明文。
- 配置 `expiresAt` 后，列表会返回 `rotationStatus`、`rotationMessage` 和 `daysUntilExpiry`；已过期凭证测试会返回 `status=EXPIRED`。
- 凭证测试成功时返回 `status=PASS`。
- Audit Center 中可以看到 `CONNECTOR_CREDENTIAL_SAVED` / `CONNECTOR_CREDENTIAL_TESTED` 等事件。
- memory 模式凭证随服务重启清空。
- JDBC 模式凭证会加密持久化，建议通过 `SHOPOPS_CONNECTOR_CREDENTIAL_SECRET` 或 `shopops.connector.credential-secret` 配置独立密钥。

## 5. 同步任务与失败重试

```powershell
$syncBody = @{
  connectorCode = "file.order-summary"
  remark = "演示同步检查"
} | ConvertTo-Json

$syncJob = Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/admin/connectors/sync-jobs" `
  -Headers $headers `
  -Body $syncBody

Invoke-RestMethod `
  -Method Get `
  -Uri "http://localhost:8080/api/admin/connectors/sync-jobs?pageNum=1&pageSize=10" `
  -Headers $headers

Invoke-RestMethod `
  -Method Get `
  -Uri "http://localhost:8080/api/admin/connectors/api-call-logs?jobId=$($syncJob.data.jobId)&pageNum=1&pageSize=10" `
  -Headers $headers

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/admin/connectors/sync-jobs/$($syncJob.data.jobId)/retry" `
  -Headers $headers
```

期望结果：
- 已配置且可读的文件连接器返回 `status=SUCCESS`。
- 未配置、文件不存在、路径异常或不可读时返回 `status=FAILED`，失败任务可以重试，`attempt` 会递增。
- 外部调用日志会记录 `endpoint=connector.status.check`、`statusCode`、`latencyMs`、`errorCode`、`errorMessage` 和 `requestId`。
- 同步触发和重试会写入 `CONNECTOR_SYNC_TRIGGERED` / `CONNECTOR_SYNC_RETRIED` 审计事件。

## 6. 验证评论与商品接口

```powershell
$commentBody = @{
  shopId = 1
  startDate = "2026-07-18"
  endDate = "2026-07-18"
  minStar = 3
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/tools/comment.query_negative/invoke" `
  -Headers $headers `
  -Body $commentBody

$productBody = @{
  shopId = 1
  startDate = "2026-07-18"
  endDate = "2026-07-18"
  limit = 2
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/tools/product.query_candidates/invoke" `
  -Headers $headers `
  -Body $productBody
```

期望结果：

- 评论接口返回 `data.connectorCode=file.negative-comments`。
- 商品接口返回 `data.connectorCode=file.product-candidates`，且 `limit=2` 时只返回 2 个候选商品。

## 7. 设计边界

这一版不是直接对接淘宝、京东、Shopify 等平台 API，而是先把业务工具和数据来源解耦：

- Agent 主链路仍调用 `order.query_summary`。
- 工具执行器仍依赖业务服务接口。
- 业务服务可以根据配置从外部文件读取数据。
- 未配置外部文件时，演示链路保持原有默认数据。
- 连接器中心展示配置、文件健康状态、凭证掩码状态、轮换提醒、同步任务和外部调用日志。
- JDBC 模式下凭证会以 AES-GCM 密文落库；memory 模式仍只用于本地演示。

后续接真实平台时，可以把文件读取替换为 HTTP API、SDK 或同步后的数据库表，而不需要改 Agent 编排和报告生成逻辑。
