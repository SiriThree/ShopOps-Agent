# 外部订单数据源演示

当前版本先完成订单指标连接器的最小闭环：`order.query_summary` 在 memory 模式下可以从 JSON 文件读取订单汇总数据；未配置文件或未命中日期时，仍回退到内置演示数据。

## 1. 示例数据

示例文件：

```text
docs/demo-data/order-summary-demo.json
```

结构：

```json
[
  {
    "tenantId": 1,
    "shopId": 1,
    "startDate": "2026-07-18",
    "endDate": "2026-07-18",
    "summary": {
      "gmv": 156780.25,
      "orderCount": 963,
      "refundAmount": 6128.00,
      "refundRate": 0.0391,
      "avgOrderAmount": 162.80,
      "compareYesterday": {
        "gmvGrowth": 0.1160,
        "orderGrowth": 0.0820
      },
      "compareSevenDayAvg": {
        "gmvGrowth": 0.0470,
        "refundRateDelta": -0.0060
      }
    }
  }
]
```

## 2. 启动方式

使用示例文件启动：

```powershell
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.arguments=--shopops.connector.order-summary.file=docs/demo-data/order-summary-demo.json"
```

如果端口被占用，可以同时指定端口：

```powershell
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.arguments=--server.port=8081 --shopops.connector.order-summary.file=docs/demo-data/order-summary-demo.json"
```

## 3. 验证接口

```powershell
$headers = @{
  "Content-Type" = "application/json"
  "X-Tenant-Id" = "1"
  "X-Shop-Id" = "1"
  "X-User-Id" = "1"
  "X-User-Roles" = "ADMIN"
}

$body = @{
  shopId = 1
  startDate = "2026-07-18"
  endDate = "2026-07-18"
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/tools/order.query_summary/invoke" `
  -Headers $headers `
  -Body $body
```

期望结果：

- `data.gmv` 为 `156780.25`。
- `data.orderCount` 为 `963`。
- `data.connectorCode` 为 `file.order-summary`。

## 4. 设计边界

这一版不是直接对接淘宝、京东、Shopify 等平台 API，而是先把业务工具和数据来源解耦：

- Agent 主链路仍调用 `order.query_summary`。
- 工具执行器仍依赖 `OrderMetricsService`。
- `OrderMetricsService` 可以根据配置从外部文件读取数据。
- 未配置外部文件时，演示链路保持原有默认数据。

后续接真实平台时，可以把文件读取替换为 HTTP API、SDK 或同步后的数据库表，而不需要改 Agent 编排和报告生成逻辑。
