# 外部业务数据源演示

当前版本已完成经营复盘核心输入的文件连接器闭环：`order.query_summary`、`comment.query_negative`、`product.query_candidates`、`ad.query_performance`、`report.query_external_metrics` 在 memory 模式下都可以从 JSON 文件读取数据；未配置文件或未命中日期时，会自动回退到内置演示数据。

连接器状态、凭证掩码、轮换提醒、同步任务和外部调用日志可以在 `/admin/connectors.html` 查看，也可以通过 `GET /api/admin/connectors/status` 验收。

## 1. 示例文件

```text
docs/demo-data/order-summary-demo.json
docs/demo-data/negative-comments-demo.json
docs/demo-data/product-candidates-demo.json
docs/demo-data/ad-performance-demo.json
docs/demo-data/external-reports-demo.json
```

## 2. 启动方式

使用示例文件启动：

```powershell
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.arguments=--shopops.connector.order-summary.file=docs/demo-data/order-summary-demo.json --shopops.connector.negative-comments.file=docs/demo-data/negative-comments-demo.json --shopops.connector.product-candidates.file=docs/demo-data/product-candidates-demo.json --shopops.connector.ad-performance.file=docs/demo-data/ad-performance-demo.json --shopops.connector.external-reports.file=docs/demo-data/external-reports-demo.json"
```

如果端口被占用：

```powershell
mvn -pl shopops-admin spring-boot:run "-Dspring-boot.run.arguments=--server.port=8081 --shopops.connector.order-summary.file=docs/demo-data/order-summary-demo.json --shopops.connector.negative-comments.file=docs/demo-data/negative-comments-demo.json --shopops.connector.product-candidates.file=docs/demo-data/product-candidates-demo.json --shopops.connector.ad-performance.file=docs/demo-data/ad-performance-demo.json --shopops.connector.external-reports.file=docs/demo-data/external-reports-demo.json"
```

## 3. 请求头

```powershell
$headers = @{
  "Content-Type" = "application/json"
  "X-Tenant-Id" = "1"
  "X-Shop-Id" = "1"
  "X-User-Id" = "1"
  "X-User-Roles" = "ADMIN"
}
```

## 4. 验证连接器状态

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "http://localhost:8080/api/admin/connectors/status" `
  -Headers $headers
```

期望结果：

- `file.order-summary` 状态为 `UP`。
- `file.negative-comments` 状态为 `UP`。
- `file.product-candidates` 状态为 `UP`。
- `file.ad-performance` 状态为 `UP`。
- `file.external-reports` 状态为 `UP`。

## 5. 验证工具接口

```powershell
$body = @{
  shopId = 1
  startDate = "2026-07-19"
  endDate = "2026-07-19"
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/tools/report.query_external_metrics/invoke" `
  -Headers $headers `
  -Body $body
```

期望结果：

- `data.connectorCode=file.external-reports`。
- `data.visitorCount=42880`。
- `data.conversionRate=0.036`。
- `data.topChannels` 包含渠道指标。

也可以分别验证：

```text
POST /api/tools/order.query_summary/invoke
POST /api/tools/comment.query_negative/invoke
POST /api/tools/product.query_candidates/invoke
POST /api/tools/ad.query_performance/invoke
```

## 6. 设计边界

这一版不是直接对接淘宝、京东、Shopify 等平台 API，而是先把业务工具和数据来源解耦：

- Agent 主链路会调用订单、评论、商品、广告、外部报表五类只读工具。
- 工具执行器依赖业务服务接口，不直接感知文件、HTTP 或数据库来源。
- 文件未配置时，演示链路使用默认数据，便于本地启动和面试展示。
- 后续接真实平台时，可以把文件读取替换为 HTTP API、SDK 或同步后的业务表，不需要改 Agent 编排和报告生成逻辑。
